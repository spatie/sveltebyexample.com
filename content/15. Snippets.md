Snippets are reusable pieces of markup. They can be rendered in a component, or passed to another component as props.

*In this example, we'll wrap our todo list in a layout component.*

---

{2} Content passed inside a component becomes a snippet prop called `children`. Named snippets can be passed as props too.

{7} Use `{@render}` to render a snippet. The parentheses are required, even when there are no parameters.

{11} Check whether an optional snippet was provided before rendering it.

```svelte
<!-- Layout.svelte -->
<script>
  let { children, footer } = $props();
</script>


<main>
  {@render children()}
</main>


{#if footer}
  <footer>
    {@render footer()}
  </footer>
{/if}
```

---

{6} Our heading and list become the layout's `children` snippet.

{12} A named snippet declared inside a component is passed to that component as a prop.

```svelte
<!-- TodoList.svelte -->
<script>
  import Layout from './Layout.svelte';
</script>

<Layout>
  <h1>Todo List</h1>
  <ul>
    <li>Walk dog</li>
  </ul>


  {#snippet footer()}
    <p>One todo at a time.</p>
  {/snippet}
</Layout>
```

---

## Snippet Parameters

{6} Snippets can receive parameters. Here, we'll reuse the same markup for each todo.

{12} Pass a value when rendering the snippet.

```svelte
<!-- TodoList.svelte -->
<script>
  let todos = $state(['Walk dog', 'Read newspaper']);
</script>


{#snippet item(task)}
  <li>{task}</li>
{/snippet}

<ul>
  {#each todos as task}
    {@render item(task)}
  {/each}
</ul>
```
