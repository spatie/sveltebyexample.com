Transitions animate elements when they enter or leave the page.

*In this example, we'll fade out a completed todo.*

---

{2} Svelte includes transitions like `fade`, `fly`, and `slide`.

{7} Removing a todo changes which elements are rendered.

{16} `transition:fade` runs when the paragraph appears or disappears. Svelte keeps it on the page until the outgoing transition finishes.

```svelte
<script>
  import { fade } from 'svelte/transition';




  let done = $state(false);
</script>


<button onclick={() => done = !done}>
  {done ? 'Undo' : 'Complete todo'}
</button>

{#if !done}
  <p transition:fade={{ duration: 200 }}>Buy milk</p>
{/if}
```
