Since Svelte `<script>` code is plain JavaScript, Svelte has great TypeScript support.

*In this example, we'll add types to our todo component.*

---

{1} Add `lang="ts"` to a component's script tag to enable TypeScript.

{4} Define a type for the component's props, including callback props.

{11} Use the type with `$props`. Our `onchecked` callback receives a boolean, not a custom event.

{17} DOM handlers receive regular HTML events. We'll tell TypeScript our input is an `HTMLInputElement`.

```svelte
<!-- Todo.svelte -->
<script lang="ts">


  type Props = {
    task: string;
    completed?: boolean;
    onchecked: (completed: boolean) => void;
  };


  let {
    task, completed = false, onchecked,
  }: Props = $props();



  function handleChange(event: Event) {
    const input = event.currentTarget as HTMLInputElement;
    onchecked(input.checked);
  }
</script>

<label>
  <input
    type="checkbox"
    checked={completed}
    onchange={handleChange}
  />
  {task}
</label>
```
