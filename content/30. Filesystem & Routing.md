SvelteKit is a meta-framework to build full-stack web applications with Svelte. SvelteKit comes with routing and the necessary build tools to create an application.

If you want to follow along, run `npx sv create` to create a new project. These examples use Svelte 5 and SvelteKit 3. SvelteKit 3 requires Node.js 22.17 or newer.

*In this example, we'll review the skeleton of a SvelteKit app and its file-based routing.*

---

{1} A hidden folder for SvelteKit to cache and temporarily store generated code.

{4} Your application lives in `src`.

{6} Use `lib` to store application code not tied to specific routes.

{10} The `routes` folder dictates the structure of your application.

{13} Each page has a `+page.svelte` component. The one in `routes` is your home page.

{17} SvelteKit also supports layout components and scripts to apply a layout to all descendants.

{21} Use subfolders for additional pages, this one will be used for the `/about` page. Page components can be accompanied by page scripts & server scripts to fetch & prepare data.

{29} This will be the index page for your lists at `/lists`. Use square brackets to add a route parameter. This will be the "show" page of a todo list at `/lists/<id>`.

{36} Your application's main CSS file and HTML skeleton.

{45} SvelteKit 3 configuration lives in `vite.config.js`, passed to the `sveltekit` plugin. Older projects used `svelte.config.js`, which is no longer supported in SvelteKit 3.

```txt
.svelte-kit


src/

——— lib/



——— routes/


——— ——— +page.svelte



——— ——— +layout.js
——— ——— +layout.svelte


——— ——— about/
——— ——— ——— +page.js
——— ——— ——— +page.server.js
——— ——— ——— +page.svelte




——— ——— lists/
——— ——— ——— +page.svelte
——— ——— ——— [id]/
——— ——— ——— ——— +page.svelte



——— app.css
——— app.html

.gitignore

package.json

README.md

vite.config.js
```

---

Use a package import to refer to `src/lib` as `#lib`. Add this mapping to `package.json`, then import files like `#lib/server/db.js`. Include the file extension. Older SvelteKit projects used `$lib` instead.

```json
{
  "imports": {
    "#lib/*": "./src/lib/*"
  }
}
```
