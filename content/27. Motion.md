Motion lets a value change gradually instead of jumping to its next value.

*In this example, we'll animate our todo progress.*

---

{2} `Tween` moves a value to its target over a fixed duration.

{6} Change `target` when a todo is completed.

{12} Read `current` to display the animated value.

```svelte
<script>
  import { Tween } from 'svelte/motion';

  const progress = new Tween(0, { duration: 300 });

  function completeTodo() {
    progress.target = Math.min(progress.target + 25, 100);
  }
</script>


<progress max="100" value={progress.current}></progress>
<button onclick={completeTodo}>Complete a todo</button>
```

---

{2} `Spring` is another way to animate a value. It moves with a little bounce instead of taking a fixed amount of time.

{6} Like a tween, a spring has a `target` and a `current` value.

```svelte
<script>
  import { Spring } from 'svelte/motion';

  const progress = new Spring(0);

  function completeTodo() {
    progress.target = Math.min(progress.target + 25, 100);
  }
</script>


<progress max="100" value={progress.current}></progress>
<button onclick={completeTodo}>Complete a todo</button>
```
