Animations move elements when their position in a list changes.

*In this example, we'll reverse the order of our todos.*

---

{2} `flip` animates an element from its old position to its new position.

{7} Each todo has a stable ID so Svelte can track it when the order changes.

{21} Use `animate:flip` on an immediate child of a keyed each block. Unlike a transition, it runs when existing items move, not when they enter or leave.

```svelte
<script>
  import { flip } from 'svelte/animate';




  let todos = $state([
    { id: 1, task: 'Mow lawn' },
    { id: 2, task: 'Walk dog' },
  ]);
</script>


<button onclick={() => todos = [...todos].reverse()}>
  Reverse todos
</button>


<ul>
  {#each todos as todo (todo.id)}
    <li animate:flip={{ duration: 200 }}>{todo.task}</li>
  {/each}
</ul>
```
